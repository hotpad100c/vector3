# Vector3

**English** | [中文](#中文)

Animate 3D shapes, text, images and even pieces of the world inside your [Flashback](https://modrinth.com/mod/flashback) replays — keyframed right on the timeline.

### Features

- **Shapes track** — a new Flashback timeline track for keyframed shapes: boxes, spheres, circles, cylinders, cones, lines, arrows, blocks, items, OBJ models, text, images and videos.
- **Area shape** — bake a region of the world and move, rotate, scale or fade it as a single object. Block entities come along too.
- **Viewport gizmo** — move, rotate, scale and reshape shapes directly in the viewport.
- **Shape Manager** — a tree of all shapes with names and parent/child hierarchy, opened from the top menu bar.
- **Editor camera** — orbit, pan and zoom around your scene, press **F** to focus on what's under the cursor.
- **Rich text** — colors and styles via JSON or `§` codes, plus custom `.ttf`/`.otf` fonts rendered with crisp signed-distance-field text.
- **Shader friendly** — works with Iris shader packs and Sodium.

### Requirements

Minecraft 26.3 · Fabric Loader · Fabric API · Flashback · RyansRenderingKit

## 中文Q

在 [Flashback](https://modrinth.com/mod/flashback) 回放中，直接在时间轴上用关键帧为 3D 图形、文字、图片甚至世界的一部分制作动画。

### 功能

- **Shapes 轨道**：为 Flashback 时间轴新增图形轨道，支持方块、球体、圆、圆柱、圆锥、线段、箭头、方块/物品、OBJ 模型、文字、图片和视频，全部可用关键帧控制。
- **区域图形**：烘焙世界中的一块区域，作为整体移动、旋转、缩放或淡出，方块实体也一并跟随。
- **视窗操纵器**：在视窗中直接移动、旋转、缩放和调整图形。
- **图形管理器**：以树状结构查看所有图形，支持命名与父子层级，从顶部菜单栏打开。
- **编辑器相机**：环绕、平移、缩放查看场景，按 **F** 聚焦鼠标所指的对象。
- **富文本**：支持 JSON 或 `§` 颜色与样式，并可使用自定义 `.ttf`/`.otf` 字体，以距离场技术清晰渲染。
- **光影友好**：兼容 Iris 光影包与 Sodium。

### 前置

Minecraft 26.3 · Fabric Loader · Fabric API · Flashback · RyansRenderingKit
